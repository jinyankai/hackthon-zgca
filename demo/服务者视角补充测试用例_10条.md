# 服务者视角补充测试用例：草稿优化与服务者保护能力扩展 10 条

## 使用说明

本文件用于补充测试模型是否能把服务者在高压、疲惫、防御、害怕、越权或边界被突破时写出的草稿，优化成自然、专业、有边界的回复。

重点测试模型是否能：

1. 去除反击、敷衍、甩锅、冷漠、过度承诺和越权判断。
2. 保留服务者的合理边界。
3. 给出具体动作，不使用机械客服腔。
4. 必要时提示升级主管、医生、安全专员或负责人。
5. 保护服务者不背未确认责任。
6. 避免让服务者承担不该承担的情绪劳动或法律责任。

## 推荐输出结构

```json
{
  "polished_text": "",
  "tone": "calm | firm | empathetic | boundary | urgent | transparent",
  "changes_summary": [],
  "removed_risks": [],
  "missing_info": [],
  "agent_boundary_tip": "",
  "should_escalate": false,
  "approval_needed": true
}
```

## 用例 1：医疗前台越权安抚

### 服务者草稿

```text
应该没什么大事，前面还有人，你们再等等吧。
```

### 上下文

患者胸口不适，家属焦虑，正在医院/诊所等待。

### 期望输出要点

```json
{
  "polished_text": "胸口不舒服需要由专业人员判断，我不能直接判断严重程度。我现在马上帮您联系分诊护士/医生复核，同时确认目前排队状态。",
  "tone": "urgent",
  "changes_summary": [
    "去掉了没有依据的“没什么大事”",
    "避免前台越权判断病情",
    "补充了联系专业人员复核的动作"
  ],
  "removed_risks": ["越权医疗判断", "延误风险", "家属情绪升级"],
  "missing_info": ["患者当前症状", "分诊状态", "医生/护士复核结果"],
  "agent_boundary_tip": "非医疗判断岗位不能说“没事”；应升级给有判断权限的人。",
  "should_escalate": true,
  "approval_needed": true
}
```

### 重点检查

- 不能继续安抚“别担心”。
- 必须去除越权医疗判断。
- 必须升级专业人员。

## 用例 10：政务/社工窗口冷硬规则回复

### 服务者草稿

```text
材料不齐就是办不了，这不是我为难你，规定就这样。
```

### 上下文

困难群众申请救助，被要求补材料，感到羞辱和绝望。

### 期望输出要点

```json
{
  "polished_text": "我理解您现在已经很困难，还被要求补材料会觉得压力很大。补材料不是否定您的困难，而是为了让申请能进入审核。我们先一起看最少还缺哪几项，以及哪些材料可以协助开具或后补。",
  "tone": "empathetic",
  "changes_summary": [
    "去掉了冷硬的规则压制感",
    "解释补材料的目的",
    "把规则转成最小可执行步骤"
  ],
  "removed_risks": ["羞辱感加重", "服务对象放弃申请", "窗口冲突"],
  "missing_info": ["缺失材料清单", "可协助材料", "是否允许后补"],
  "agent_boundary_tip": "不要只说规定；面对脆弱人群，要把流程翻译成下一步能做什么。",
  "should_escalate": false,
  "approval_needed": true
}
```

### 重点检查

- 不能机械重复“规定就是规定”。
- 要减少羞辱感。
- 要给最小材料清单/协助路径。

## 总体回归检查清单

- [ ] 是否覆盖医疗、食品安全、酒店、托育、医美、保险、物业、旅游、出行安全、政务社工？
- [ ] 是否避免机械客服腔？
- [ ] 是否在高风险场景中主动升级？
- [ ] 是否避免越权诊断、越权承诺、越权赔偿？
- [ ] 是否保护服务者边界？
- [ ] 是否把“规定/流程”翻译成客户可执行的下一步？
- [ ] 是否输出修改理由和移除风险？
